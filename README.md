# Página de venta — Hazlo Fácil

## Cambiar textos
- `src/config.ts`: marca, lema, correo, tiempo de entrega y los planes.
- `index.html`: título que aparece en la pestaña del navegador.

## Probar en tu computadora
    npm install
    npm run dev

## Publicar en Vercel (gratis)
1. Sube esta carpeta a un repositorio nuevo en GitHub.
2. En vercel.com → "Add New Project" → elige el repositorio → "Deploy".
3. Configura los avisos por WhatsApp y correo: ver `LEEME-WHATSAPP.md`.
4. Vercel te da una dirección como `hazlofacil.vercel.app`. Si compras un dominio, se agrega en Settings → Domains.
